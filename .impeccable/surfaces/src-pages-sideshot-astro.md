# skills.victorsaly.com/sideshot

Scope: SideShot's landing page, inside the shared "Victor Saly · Skills" frame. Visitor mode: Persuade.
Audience: developers with a coding agent, arriving from a README, LinkedIn or search, often on a phone, deciding in
about a minute. Action: copy the install command; GitHub repo second. Proof: the real before/after pictures from
agentic-blog #151 and the rings-and-marks example (victorsaly/sideshot/docs/assets). Constraints: no invented
counts, users or quotes; agent-agnostic; WCAG 2.2 AA; reduced motion respected.

## Direction contract

THESIS: The page is the pull request SideShot writes into. It refuses the category default of hero, three feature
cards and a code block: here the proof is the PR table itself, and the offer is the last added line.

OWN-WORLD: Paper white and ink black, one marigold. GitHub-PR grammar rebuilt in Victor's ink language: a PR title
row with a state pill, a conversation column of ruled blocks, diff gutters (− in grey, + in marigold), monospace for
commands and line numbers, Atkinson Hyperlegible for prose. Rules in three weights, no shadows, no cards, no
rounded chrome except the SideShot mark's squares.

STORY: The visitor sees a PR titled with a real change, the before/after table SideShot put there, and understands
in one look that this is what their PRs get. Each section below is a hunk that adds a capability (rings and marks,
your screens, any agent). They copy the install line.

FIRST VIEWPORT: Top: frame bar "Victor Saly · Skills / SideShot" with the SideShot mark. Then the PR header:
"SideShot this PR" at display size, state pill "Open", a meta line. Below, the real before/after table filling the
width (desk pair, phone pair on narrow screens). The install command as a diff line "+ npx skills add
victorsaly/sideshot -g" with a Copy control, visible without scrolling on a 1280×800 desk and reached in one
scroll on a 390 phone.

FORM: "The page is a pull request", position 7 on the ranked list; seed key 8e174304. Signature interaction: the
install line is a + diff line; Copy fills it marigold and the gutter turns to a tick. Motion: none unasked, except
that copy confirmation (reduced motion: instant).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
