Purchase order approval

This path is a loop: it repeats

Pick a box or a line to see only what it connects to.

Notes

Submit order
The requester enters supplier, items and cost centre.
Validate order
Checks the supplier is active and the totals add up.
Within budget?
Compares the order total with what is left in the cost centre budget.
Manager approval
The line manager reviews the order and the reason for it.
Revise order
The requester changes quantities, supplier or cost centre, then resubmits.
Approved?
The manager approves, or sends it back with a comment.
Send to supplier
The order is sent to the supplier.
Order placed
The supplier has the order. Nothing more happens in this flow.
